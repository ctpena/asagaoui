This is used for content consisting of multiple pairs of “what you want to explain” and “the corresponding description,” with each pair treated as a single entry.

```html {preview="true"}
<dl class="description-list">
    <dt>The Bodmin Monster</dt>
    <dd>A large feline native to Bodmin Moor. </dd>
    <dt>Moggar </dt>
    <dd>A sea serpent. </dd>
    <dt>Owlman </dt>
    <dd>A giant creature resembling an owl. </dd>
</dl>
```
