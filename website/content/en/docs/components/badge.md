A component that graphically displays the state or situation of the main information. In the Digital Agency Design System, it is defined as a [Chip Label](https://design.digital.go.jp/dads/components/chip-label/).

## Types

```html {preview="flex"}
<span class="badge">Label</span>
<span class="badge badge-outline">Label</span>
<span class="badge badge-filled-outline">Label</span>
<span class="badge badge-fill">Label</span>
```
