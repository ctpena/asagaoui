An element for making it easy to display and delete arbitrary information that has been itemized. It is effective when itemizing attributes or user information and arranging or deleting them.

```html {preview="true"}
<span class="chip-tag">Label</span>
<span class="chip-tag">Label<button class="chip-tag-cancel"></button></span>
```
