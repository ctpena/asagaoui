A UI with menu items arranged vertically, useful for mobile menus and side menus.

```html {preview="true"}
<ul class="menulist">
    <li class="menulist-item">
        <a href="" class="menulist-link">
            Menu Item 1
        </a>
    </li>
    <li class="menulist-item">
        <a href="" class="menulist-link">
            Menu Item 2
        </a>
    </li>
    <li class="menulist-item">
        <a href="" class="menulist-link">
            Menu Item 3
        </a>
    </li>
</ul>
```

## Resizing

You can change the size of `.menulist-link` by adding the following classes:

- `.is-sm`
- `.is-md`
