A UI component for implementing menus commonly used on websites.

## Example

{{% code-snippet lang="html" preview="true" %}}
<ul class="menulist">
    <li class="menulist-item">
        <a href="" class="menulist-title">Menu Title</a>
        <ul class="menulist">
            <li class="menulist-item">
                <a href="" class="menulist-link ">Menu Item</a>
            </li>
            <li class="menulist-item">
                <a href="" class="menulist-link ">Menu Item</a>
            </li>
        </ul>
    </li>
</ul>
{{% /code-snippet %}}
