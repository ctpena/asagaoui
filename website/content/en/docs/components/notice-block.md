A notice block is a highlighted piece of supplementary information. It is most effective when used to supplement help for the input fields of a procedural form, such as concrete examples of input variations or examples of documents needed when filling in the form. Note: conditions or constraints on the input or operation itself, such as the character types that can be entered, should be provided using the "Support text" part of the "Input text" component.

```html {preview="true"}
<div class="notice-block">
    <p class="notice-block-title">Title</p>
    <div class="notice-block-body">
        <p class="notice-block-description">Text text text text text</p>
    </div>
</div>
```
