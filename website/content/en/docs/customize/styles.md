These elements are pre-configured as variables and can be easily reused.

## Contents of the styles folder

### _color.scss

Defines the colors used in Color 2.0.

### _ratios.scss

Defines aspect ratios.

### _rounding.scss

Defines corner shapes (border-radius).

### _spacing.scss

Defines the units used for spacing.

### _theme.scss

Defines color themes such as link colors. You can add your own color modes. This feature is currently incomplete.

### _typography.scss

Defines settings related to typography.
