These elements are pre-configured as variables and are easily reusable.

## Contents of the styles folder

### _color.scss

Defines colors used in Color 2.0.

### _ratios.scss

Defines aspect ratios.

### _rounding.scss

Defines the size of corner shapes (corner radius).

### _spacing.scss

Defines unit units used for spacing.

### _theme.scss

Defines color themes such as link colors. You can add your own color modes. Currently, this function is incomplete.

### _typography.scss

Defines settings related to typography.
