This is a utility class that allows you to change the background color. It can be used with `.bg-`. Please use it with accessibility in mind. In some cases, you may need to change the text color as well.

To change the text color, use the [colors](docs/utilities/colors/) utility class.



## How to Use

```html {preview="true"}
<div class="bg-red-500">Change background color </div>
```
