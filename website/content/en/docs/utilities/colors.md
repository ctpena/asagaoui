This is a utility class that allows you to change text color. It can be used with `.text-`. Please use it with accessibility in mind. In some cases, you may need to change the background color.

To change the background color, use the [background](docs/utilities/background/) utility class.

## Usage

```html {preview="true"}
<div class="text-red-500">Change text color </div>
```
