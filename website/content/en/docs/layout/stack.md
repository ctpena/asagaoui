---
title: Stack
---

Can be used to arrange elements vertically or horizontally using `display: flex;`.

Vertical Stacking

{{< code-snippet lang="html" preview="true" >}}
<div class="vstack g-3">
    <div class="p-4 bg-magenta-500"></div>
    <div class="p-4 bg-magenta-500"></div>
</div>
{{< /code-snippet >}}

Horizontal Stacking

{{< code-snippet lang="html" preview="true" >}}
<div class="hstack g-3">
    <div class="p-4 bg-magenta-500"></div>
    <div class="p-4 bg-magenta-500"></div>
</div>
{{< /code-snippet >}}
