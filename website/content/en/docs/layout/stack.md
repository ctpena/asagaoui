Can be used to arrange vertically or horizontally using `display: flex;`.

Vertical alignment:

```html {preview="true"}
<div class="vstack g-3">
    <div class="p-4 bg-magenta-500"></div>
    <div class="p-4 bg-magenta-500"></div>
</div>
```

Horizontal alignment:

```html {preview="true"}
<div class="hstack g-3">
    <div class="p-4 bg-magenta-500"></div>
    <div class="p-4 bg-magenta-500"></div>
</div>
```
