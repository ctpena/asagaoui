AsagaoUI features a distinctive grid system.

## Grid

The `grid` class, with `display: grid;` assigned, provides a 12-column grid layout.

Example Code

{{< code-snippet lang="html" preview="true" >}}
<div class="grid g-1">
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="col-2 p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
</div>
{{< /code-snippet >}}
