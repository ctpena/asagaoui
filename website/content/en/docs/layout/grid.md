AsagaoUI has a characteristic grid system.

## grid

The `grid`, which is assigned `display: grid;`, provides a 12-column grid layout.

Code example:

```html {preview="true"}
<div class="grid g-1">
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="col-2 p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
    <div class="p-4 bg-magenta-500">
    </div>
</div>
```
