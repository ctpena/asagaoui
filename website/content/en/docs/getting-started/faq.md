We've compiled frequently asked questions and answers about AsagaoUI.
If you have any further questions, please feel free to contact us.

What is AsagaoUI?
: AsagaoUI is a CSS framework with UI components built based on the <a href="https://design.digital.go.jp/">Digital Agency Design System</a>.

Does AsagaoUI ensure accessibility?
: No, AsagaoUI does not include special implementations specifically for accessibility. The final responsibility for accessibility lies with the web service provider. For more information, please see <a href="/docs/getting-started/accessibility/">Accessibility</a>.

Is JavaScript required?
: Basically, it is not required. However, it is necessary when using the date picker or code snippet components.
