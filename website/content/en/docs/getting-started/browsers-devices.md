AsagaoUI only supports the latest releases of Chrome and Firefox. Other browsers are not explicitly supported, but in many cases they should work fine. 
Some components may contain text indicating that they do not work with specific browsers or devices. If compatibility with a wide range of browsers is required, please perform appropriate operational verification and modify the code as necessary.

## Browser and Device Support Policy

AsagaoUI does not provide additional code, such as CSS prefixes, that supports a wider range of browsers. If necessary, users will need to add them themselves.

Basically, it only supports the latest major browsers, and if other options are required, you will need to make some corrections on your own.
