メニュー項目を縦に配置したUIでモバイルメニューやサイドメニューで活躍します。

```html {preview="true"}
<ul class="menulist">
    <li class="menulist-item">
        <a href="" class="menulist-link">
            メニュー項目1
        </a>
    </li>
    <li class="menulist-item">
        <a href="" class="menulist-link">
            メニュー項目2
        </a>
    </li>
    <li class="menulist-item">
        <a href="" class="menulist-link">
            メニュー項目3
        </a>
    </li>
</ul>
```

## サイズ変更

次のクラスを追加することで`.menulist-link`のサイズを変更することができます。

- `.is-sm`
- `.is-md`
