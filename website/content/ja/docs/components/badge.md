メインの情報に状態や状況をグラフィカルに表示するコンポーネントです。デジタル庁デザインシステムでは[チップラベル](https://design.digital.go.jp/dads/components/chip-label/)として定義されています。

## 種類

```html {preview="flex"}
<span class="badge">ラベル</span>
<span class="badge badge-outline">ラベル</span>
<span class="badge badge-filled-outline">ラベル</span>
<span class="badge badge-fill">ラベル</span>
```
