分割されたコンテンツを移動できるナビゲーションUI

`.prev`クラスと`.next`クラスによって、装飾できます。

```html {preview="true"}
<div class="page-navigation">
    <a class="page-navigation-item prev" href="">モバイルメニュー</a>
    <a class="page-navigation-item next" href="">プログレスインジケーター</a>
</div>
```
