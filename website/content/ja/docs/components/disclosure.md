ディスクロージャーは、メイン情報に対する追加情報を折りたたんで提示するときに使用します。

```html {preview="true"}
<details class="disclosure">
  <summary class="disclosure-header">
    ダミーテキストとは何ですか？
  </summary>
  <div class="disclosure-body">
    <div>これはダミーテキストです。</div>
    <div>ダミーテキストは、デザインやレイアウトの作成時に使用される仮の文章です。</div>
  </div>
</details>
```

## デジタル庁デザインシステムとの違い

[デジタル庁デザインシステムv2.13.0](https://design.digital.go.jp/components/accordion/)
では、ディスクロージャー展開時のリターンリンクが実装されていますが、AsagaoUIでは次の理由により実装していません。

- ユーザビリティの向上: ブラウザ標準のスクロール機能で十分対応可能
- アクセシビリティの配慮: 追加要素による認知負荷の軽減
- 保守性の向上と維持

特に長いコンテンツでリターンリンクが必要な場合は、個別にカスタマイズして実装することを推奨します。
