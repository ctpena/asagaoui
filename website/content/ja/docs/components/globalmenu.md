---
title: グローバルメニュー
weight: 80
---

グローバルメニューは主要なメニュー表示に用いることが可能なコンポーネントで、`.globalmenu`クラスを用いることで使用できます。`.globalmenu-link`
に`.active`クラスを追加することでスタイルを切り替えることが可能です。

{{< code-snippet lang="html" preview="true" >}}
<ul class="globalmenu">
    <li class="globalmenu-item">
        <a class="globalmenu-link" href="">リンク</a>
    </li>
    <li class="globalmenu-item">
        <a class="globalmenu-link active" href="">アクティブ</a>
    </li>
    <li class="globalmenu-item">
        <a class="globalmenu-link" href="">リンク</a>
    </li>
</ul>
{{< /code-snippet >}}
