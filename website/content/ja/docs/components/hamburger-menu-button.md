モバイルメニューで用いられるハンバーガーボタンを実装するコンポーネントです。

アイコンと文字が横並びか縦並びかは自動的に調整されますが、明示的に指定することも可能です。

```html {preview="flex"}
<button
        class="hamburger-iconbtn"
        type="button">
    <i class="hamburger-icon"></i>
    メニュー
</button>
<button
        class="hamburger-btn"
        type="button">
    <i class="hamburger-icon"></i>
    メニュー
</button>
```
