「説明したいこと」と「その説明文」のペアを1つの項目として数え、それが複数連なるようなコンテンツの時に使用します。

```html {preview="true"}
<dl class="description-list">
    <dt>ボドミンの怪獣</dt>
    <dd>ボドミンムーアに生息する大型のネコ科動物です。</dd>
    <dt>モーガー</dt>
    <dd>海蛇。</dd>
    <dt>オウルマン</dt>
    <dd>フクロウに似た巨大な生き物です。</dd>
</dl>
```
