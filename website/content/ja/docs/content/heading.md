見出しは、主にページの冒頭やパラグラフの前に配置される、ページやパラグラフの主題を表すコンポーネントです。

## 種類

### ショルダーテキスト

```html {preview="true"}
<hgroup class="">
    <p class="hs">ショルダーテキスト</p>
    <h2 class="h2">見出しテキスト</h2>
</hgroup>
```

### チップ（縦線）

```html {preview="true"}
<h2 class="h2 hchip">見出しテキスト</h2>
```

### 下線

```html {preview="true"}
<h2 class="h2 hrule">見出しテキスト</h2>
```

### アイコン

## 見出しレベル

```html {preview="true"}
<hgroup class="">
    <p class="">ショルダーテキスト</p>
    <h2 class="">見出しテキスト</h2>
</hgroup>
```
