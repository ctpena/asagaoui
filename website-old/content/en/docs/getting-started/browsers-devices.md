AsagaoUI supports only the latest releases of Chrome and Firefox. Other browsers are not explicitly supported, but in many cases, they should function without issues.
Some components may include notes stating they do not work on specific browsers or devices. If support for a wide range of browsers is required, please perform appropriate operational verification and modify the code as necessary.

## Browser and Device Support Policy

The code provided by AsagaoUI does not include additional code, such as CSS prefixes, to support a wider range of browsers. If necessary, users must add them.

Basically, it supports only the major latest browsers. If other options are required, you will need to make your own modifications.
