This is an original AsagaoUI component. This component is not defined in the Digital Agency Design System.

It can be conveniently used for displaying multiple pieces of content or images by sliding them horizontally. Since it is composed entirely of CSS, JavaScript is not required.

{{% code-snippet lang="html" preview="true" %}}
<div class="carousel">
    <ul class="carousel-inner">
        <li class="carousel-item">
            <img src="https://placehold.co/1280x720" alt="">
        </li>
        <li class="carousel-item">
            <img src="https://placehold.co/1280x720" alt="">
        </li>
    </ul>
</div>
{{% /code-snippet %}}
