---
title: Global Menu
weight: 80
---

The global menu is a component that can be used for displaying primary navigation. You can use it with the `.globalmenu` class. By adding the `.active` class to `.globalmenu-link`, you can switch styles.

{{< code-snippet lang="html" preview="true" >}}
<ul class="globalmenu">
    <li class="globalmenu-item">
        <a class="globalmenu-link" href="">Link</a>
    </li>
    <li class="globalmenu-item">
        <a class="globalmenu-link active" href="">Active</a>
    </li>
    <li class="globalmenu-item">
        <a class="globalmenu-link" href="">Link</a>
    </li>
</ul>
{{< /code-snippet >}}
